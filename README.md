# 🎮 Pedra, Papel e Tesoura

Aplicativo desenvolvido em **Kotlin para Android** como atividade de programação.

O projeto implementa o jogo clássico de **Pedra, Papel e Tesoura**, permitindo que o usuário escolha sua jogada através de imagens.

## 📱 Funcionamento

O jogador pode clicar em uma das três imagens:

* 🪨 Pedra
* 📄 Papel
* ✂️ Tesoura

Após a escolha, o aplicativo sorteia aleatoriamente a jogada do oponente e informa o resultado da partida.

## 🏆 Placar

O aplicativo possui um placar que registra:

* Vitórias
* Derrotas
* Empates

O placar é atualizado automaticamente a cada rodada.

## 🖼️ Interface

As imagens de **pedra**, **papel** e **tesoura** funcionam como opções clicáveis para o jogador.

Também é exibida na tela a imagem escolhida aleatoriamente pelo oponente, juntamente com o resultado da partida.
